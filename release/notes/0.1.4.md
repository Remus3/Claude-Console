# Claude Console 0.1.4

A reliability and polish release: safer process handling, a choice of what happens
after `/clear`, clearer progress times, an opt-in API spend reader, and setup profile
fixes. Everything below is new since 0.1.3.

## New

- **After /clear** (Settings): `Refresh the workflow rows` (default, as before) or
  `Reopen`, which restarts that pane's Claude process fresh in the same slot, with a
  new session and a wiped buffer. A pane whose last act was a `/clear` no longer
  leaves a "reopen" chip or a Resume button behind: there is nothing to continue.
- **Progress times**: pane run rows, the pane header and the status card show
  `started 1:55PM - 25% ~22.5m of 30m Remain [2:25PM]` (when a task records its start
  time), so you can see when a task began and when it should end.
- **API spend (opt-in, off by default)**: Settings > API keys and credits can read
  month-to-date API spend per account from an Admin key in the user environment
  (`CLAUDE_CONSOLE_ACCT1_API_KEY` / `CLAUDE_CONSOLE_ACCT2_API_KEY`). Numbers only; the
  key is read server side and never shown. Until you tick the opt-in the console makes
  no call to `api.anthropic.com` (the host is listed as opt-in in
  `installer/egress.json`).

## Fixed

- Closing or restarting a pane could end an unrelated process: the terminal library
  killed the shell's process id about 5 s after the shell had already exited, and
  Windows may have given that id to another program by then. The console now ends the
  pane's processes while the shell is still alive and turns off the late kill.
- No `taskkill /T` by bare process id in the console: process clean-up ends only
  verified descendants (created after their parent), one at a time, deepest first.
- Usage strip: when two accounts share one account id, the first configured one is
  used; defaults are 7 days, Acc 1 and Acc 2; Acc 2 is off without a second login.
- Setup profile: account checks warn about missing account folders, user-scope
  settings reach every account folder, plugin items write `enabledPlugins`, eight more
  live settings are modelled, quiet keys for a second account reach only that account,
  and the review step remembers your selection.

## Security

- `CLAUDE_CONSOLE_*_API_KEY` variables are removed from every pane's environment, so
  an Admin key never reaches Claude, a shell or the tools they run.
- Pane create and restart routes are loopback-only like every other write route.
- Command labels drop secret-looking flags and their values.

## Interface

- Over twenty wording, layout and accessibility fixes from a second UI review (wider
  progress cells so the finish time shows, clearer error and warning states, labels on
  icon buttons).

## Update

From 0.1.0 to 0.1.3: `claude-console update --yes`, the Update badge in the console,
or run the installer again:

```powershell
irm https://github.com/Remus3/Claude-Console/releases/latest/download/install.ps1 | iex
```

The API spend reader stays off after the update until you turn it on.
