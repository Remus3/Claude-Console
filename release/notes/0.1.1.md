# Claude Console 0.1.1

A fix release for stop and uninstall.

## Fixed

- `claude-console stop` said "stopped" while the server process that opened the app
  window kept running: the server stopped listening but waited on the window's open
  connections. The server now ends every WebSocket and HTTP connection when it shuts
  down and exits after a 3 s grace period at most.
- `stop` now waits for the server process itself to exit, not only for port 7800 to
  close. It reports a failure when the process is still running after the timeout
  (`--timeout S`, default 10 s); `stop --force` ends it.
- `claude-console uninstall` printed `EPERM` for the `app` folder, left it behind and
  still exited 0. It now stops the server (and any leftover server of an older version)
  first, retries the removal, and exits non-zero with one `uninstall incomplete: ...`
  line naming what is left whenever anything remains. It never reports success while
  files remain.
- `claude-console.cmd` passes the exit code on (it returned 0 to PowerShell after a
  failed command).
- An update restart waits for the old server process to exit before it starts the new
  version.

## Update

From 0.1.0: `claude-console update --yes`, the Update badge in the console, or run the
installer again:

```powershell
irm https://github.com/Remus3/claude-console/releases/latest/download/install.ps1 | iex
```
