# Claude Console 0.1.5

See at a glance which pane needs you, keep a pane's history intact, and read setup and
update steps that say what they really do.

## New

- **Needs-you list**: the top-bar `? N` button counts the panes that need you (a
  permission prompt) or wait unread after a turn. It opens one line per pane
  (`? api - needs you - 3m`, `- web - waiting - 1m`), needs-you first, then oldest
  first; click a line to restore and focus that pane.
- **Ctrl+Alt+U** jumps to the newest unread pane (restores it if minimized), also
  from inside a terminal.
- **Progress line**: a thin line along the pane header shows while Claude generates,
  taken from Claude Code's own progress signal.
- **GPU rendering**: visible panes draw with the GPU, at most 16 at a time; a pane that
  loses its GPU context falls back to the regular renderer and keeps working. Measured
  with 8 busy panes: the same frame times, about half the page's main-thread work and
  about a third less browser CPU.
- **Read machine** (in the Machine advisor: the `...` menu, or Settings): one read-only
  query of your hardware and OS, saved on this computer only, with no host name, user
  name, address or serial number. Claude panes are told where the file is and open it
  only when a task needs it.

## Changed

- **Updates**: nothing checks in the background, and the auto-update box is gone from
  Settings because it promised a check that never ran. Checks run when you press **Check
  now** (Settings > Updates & repair) or from the optional daily task
  (`claude-console autoupdate --register`). Without that task, you see no update badge
  until you press Check now.
- **Permission prompts**: the author's preset no longer turns them off. High-risk items
  in a preset now wait for a box you tick yourself.
- **Uninstall** stops while a setup profile is applied and tells you how to remove it
  first; `--keep-profile` overrides.
- **Projects**: more folders are scanned by default (your home folder, Documents, Desktop,
  `source\repos`, `Projects` and `code`), and a git project you open with **+ New** stays
  listed. **Remove** is now **Hide**, and files were never touched; **Show**, in the
  Projects part of Settings, brings a hidden project back. The list is narrower, with one
  line per project, and a status card shows git only when there is something to act on.
- **Text size**: the top-bar A- and A+ buttons are gone; set the default in Settings >
  **Terminal font px**.
- **Pane buttons**: key buttons default to Esc and S-Tab, and Attach sits beside Send.
  The `/done` chip shows only where the command exists, in that pane's project or account.
- **Setup wizard**: it still opens after install and now says it is optional. **Skip for
  now** writes nothing, and the `...` menu, **Run setup...**, brings it back.
- **Settings** is reordered and more compact. Text sizes are set in pixels per level, and
  the theme applies as soon as you pick it (the Toggle button is gone; Cancel puts the old
  theme back). `Contribute?` is now **Save my edits as a patch**.
- **Narrow windows**: on a phone-width window the Projects and Status panels open as
  drawers below the top bar, and up to 1100 px wide the Status panel does.
- **Public repo**: `audit-agent.md` is no longer in its docs folder. That file was the
  prompt for the project's internal docs review and had no reader outside.

## Fixed

- **Scrollback**: on Windows 10 a pane's history could repeat, come out garbled or be
  cut short after a resize, and Find could miss it. Panes now use the terminal library's
  own console host. A reload or reconnect also restores up to your Scrollback setting
  (at most 8 MB per pane), not just the last 400 KB.
- **Stop everything** (`claude-console stop-all --yes` and `recover.ps1 -Stop`) still used
  `taskkill /T`, which 0.1.4 said was gone. It now ends only verified descendants of a
  recorded process, one at a time, as the rest of the console does. Background runs from
  the setup profile end the same careful way.
- **Resume after Stop everything**: the Stop dialog now offers Resume whenever a stop is
  open, also after a restart or a stop from a terminal, and one Resume undoes them all.
- **/done receipt**: the line that says a session is safe to clear no longer loses its
  last letters.
- **May delete** in the setup wizard said `nothing` for scheduled tasks that do delete.
  Each task now says what it may delete.
- **Claude Code installed later**: the console finds it the next time you open a pane, with
  no restart. If it is missing, the console's own dialog says what to do.
- **Failed start**: the console now says why it could not start, such as a port already
  in use. If Edge is missing, it opens in your default browser.
- **Lost connection**: if a pane or the server is gone when you send, your typed prompt
  stays in the box and the pane says why.
- **Narrow panes** keep their titles; shell panes no longer show Claude's buttons.
- **Recovery prompt and crash report**: a temp folder outside your home folder could
  stay in the text as a full path. The recovery prompt, the crash report, the saved patch
  and `recover.ps1 -Prompt` now remove it, in any letter case.
- **`recover.ps1 -Prompt`** failed and wrote no prompt whenever the console's logs held an
  error line, which is when you need it most. It now writes the prompt, with those lines.
- **Setup profile**: its helpers no longer carry a default scratch folder from the
  author's machine. They use one only when you set `KIT_SIDECAR_ROOT`.

## Known issue

- **A rare silent exit, cause not found**: while testing this release on Windows 10, a
  Node process running one test file sometimes ended with exit code 3221226505
  (0xC0000409) and no error message. It has appeared only in test runs: about 240 test
  starts of the real server and about 1,200 other Node starts showed none, on one
  computer, and those were mostly short starts. It cannot yet be said whether 0.1.4 does
  it at the same rate. If the console disappears, start it again. If an update stops on a
  failed self-test with that code in its log, your old version stays in place; run the
  update again. Reports of this code are welcome.

## Update

Press **Check now**, then the Update badge or **Update now**; or run
`claude-console update --yes`; or run the install command again.
