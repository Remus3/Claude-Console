# Claude Console 0.1.2

A fix release for uninstall.

## Fixed

- `claude-console uninstall --purge` removed everything but exited 1 and printed
  "The system cannot find the path specified." twice. The launcher and the install
  folder were removed on a fixed 3 s timer, sometimes while the command was still
  running. They are now removed by a small cleanup script in `%TEMP%` that first waits
  for the command (and the `claude-console.cmd` that ran it) to exit, then deletes
  itself. Plain `uninstall` and `uninstall --purge` both finish, print their result and
  exit 0 before anything is removed.
- `claude-console.cmd` passes the command's exact exit code on (0.1.1 reported every
  failure as 1).

## Update

From 0.1.0 or 0.1.1: `claude-console update --yes`, the Update badge in the console, or
run the installer again:

```powershell
irm https://github.com/Remus3/claude-console/releases/latest/download/install.ps1 | iex
```
