# Claude Console 0.1.0

First public release.

## Install

```powershell
irm https://github.com/Remus3/claude-console/releases/latest/download/install.ps1 | iex
```

Windows 10 / 11. The installer adds Node.js LTS and Git when they are missing, checks
the download against `SHA256SUMS.txt`, installs to
`%LOCALAPPDATA%\Programs\claude-console` and starts the console. Rather not run a
remote script? Download `install.ps1`, the zip and `SHA256SUMS.txt`, read the script,
then run `powershell -ExecutionPolicy Bypass -File .\install.ps1 -Zip .\claude-console-0.1.0.zip`.
Claude panes need the Claude Code CLI (`irm https://claude.ai/install.ps1 | iex`).

## What is in it

- Tiled terminal panes for Claude Code sessions and shells (node-pty + xterm.js) in an
  app window, local only (127.0.0.1, per-start token).
- A project list of the git repos on your drive, with branch, changes, hand-off and
  progress files.
- Settings, layouts and sidebar groups saved on your computer.
- Health & cleanup, a scheduled-task view, a usage panel.
- Update-aware install: a daily release check with an Update badge, 3-way merge of your
  local changes, backup and self-test before switching, rollback, repair and fresh
  reinstall, uninstall (Apps & features or `claude-console uninstall`).

## Assets

| File | What |
|---|---|
| `install.ps1` | the one-command installer |
| `claude-console-0.1.0.zip` | the release (one `claude-console-0.1.0/` folder with `MANIFEST.json`) |
| `SHA256SUMS.txt` | SHA-256 of the zip and of `install.ps1` |
