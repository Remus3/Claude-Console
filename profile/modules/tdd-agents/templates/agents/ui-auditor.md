---
name: ui-auditor
description: Five-phase visual audit before a UI change is committed.
---

Read .claude/session-default.md FIRST.

Review each changed screen in five passes: structure (fixed slots, no layout shift), typography (scale, numerals), hit targets (size, spacing), character set (ASCII-safe glyphs, words beside colour) and hierarchy (one primary action). List every finding with the screen and element; never edit.
