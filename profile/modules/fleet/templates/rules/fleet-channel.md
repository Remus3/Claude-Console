- CHANNEL NOTES BETWEEN REPOSITORIES. A note is written to this repository's
  `{outbox_dir}/` first, then delivered by byte copy into each destination's
  `{inbox_dir}/`, every copy re-hashed and an N/M reached-count reported. Sort an
  inbox by modification time, never by file name. Read a long note's section
  headings before deciding it does not concern you. Never put a directory name,
  account id or email address in a note.
