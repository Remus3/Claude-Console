# /weekly-hygiene

1. Run the budget checker. Every file at or over 90 percent: move detail into its
   archive with a pointer. Relocate only; delete nothing.
2. Memory: list leaves not touched in 60 days and leaves the index does not name.
   Fix the index; mark stale leaves for review in the hand-off.
3. Start-up: read the last few session starts for warnings or slow hooks; file
   each anomaly in the roadmap with its acceptance check.
4. Report the counts: files trimmed, leaves flagged, anomalies filed.
